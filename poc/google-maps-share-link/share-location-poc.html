SHARE → LOCATION PoC

Google Maps共有から地点を自動確定

任意ピンは共有タイトルの緯度経度を直接採用し、施設・住所は共有URLをGoogle公式APIで解決します。

共有受信準備

Service Workerを確認中…
{
  "serviceWorker": "checking",
  "controller": false
}

ここが ready になってからGoogle Mapsへ戻り、共有してください。共有POSTはService Workerが端末内で受け取ります。

使い方

  1. この画面でService Workerが ready になることを確認
  2. Google Mapsで地点を開く
  3. 「共有」を押す
  4. 「想いの方角 Share PoC」を選ぶ

任意ピンでtitleが緯度経度の場合は外部APIを呼びません。施設等のURL解決時だけCloudflare Pages Function経由でGoogle APIを利用します。

判定結果

共有待ちです。
{
  "latitude": null,
  "longitude": null,
  "method": null,
  "apiCalled": false
}

受信した共有データ

{
  "title": null,
  "text": null,
