# ADR-0002: 保存先は端末内のみ、最大5か所とする

## Status

Proposed

## Context

「想いの方角」は、場所を大量に収集・管理するアプリではなく、本人にとって大切な少数の場所を静かに向くための道具である。

保存対象には「故郷」「家族」「大切な人」「墓所」「思い出の場所」など、センシティブな意味付けが含まれる可能性がある。

## Decision

MVPでは以下とする。

- 登録地点は最大5か所
- 保存先はブラウザのlocalStorage
- ログイン機能は設けない
- サーバーDBへ登録地点を送信しない
- 保存する基本項目は表示名、緯度、経度、schema version
- Google Mapsの検索履歴や不要な住所情報は保存しない

## Consequences

### Positive

- プライバシー境界が明確
- DB、認証、同期処理が不要
- 実装・運用コストが小さい
- 「大切な場所だけを残す」というプロダクト思想を保てる

### Negative

- 端末変更時にデータは自動移行されない
- ブラウザデータ削除で登録内容が失われる
- 複数端末同期はできない

## Alternatives Considered

### クラウドDB保存

端末間同期は可能になるが、センシティブな意味付けを持つ地点をサーバーで扱う必要が生じるためMVPでは採用しない。

### 保存件数を無制限にする

場所コレクションアプリへ性格が寄るため採用しない。

## Future Consideration

利用実績から必要性が確認できた場合のみ、ユーザー自身が明示的に操作するバックアップ/復元方式を別途検討する。
